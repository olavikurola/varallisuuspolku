Open data and method

Plans shared per month

What this data is: plans voluntarily shared by Varallisuuspolku users — not actual realised wealth. The sample is self-selected (people who use the tool), and the figures are a cross-section, not a follow-up study.

Privacy: no identifiers, amounts rounded, distributions published only from groups of ≥ 30 plans. Raw data is never published — only aggregates: stats.json · server code
